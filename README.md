# Chris Cowden — Notes

A deliberately small personal blog for GitHub Pages.

## Publishing

This repository is designed to be named `Flawed-Fractal.github.io`. Once pushed
to that repository on GitHub, the site will appear at:

https://flawed-fractal.github.io/

## Adding a post

1. Copy `posts/a-small-place.html` to a new file in `posts/`.
2. Replace the title, date, description, and article text.
3. Add the new entry to `index.html`, `feed.xml`, and `sitemap.xml`.

The site uses no framework, tracking, external fonts, or build process.
